# etl_pipeline
# 📊 Executive KPI & Sales Analytics Dashboard

Aplikasi dashboard interaktif berbasis **Streamlit** yang dirancang untuk membantu *stakeholder* menganalisis performa bisnis, pencapaian target KPI, dan tren penjualan secara visual, responsif, dan real-time.

---

## 🎯 Fitur Utama

* **Executive Scorecard:** Menampilkan 4 KPI utama (*Total Revenue, Order Volume, Conversion Rate, Average Order Value*) lengkap dengan indikator pertumbuhan ($\uparrow/\downarrow$).
* **Interactive Dynamic Filters:** Filter global via *Sidebar* berdasarkan rentang waktu (*Date Range*), wilayah (*Region*), dan kategori produk.
* **Deep-Dive Tabbed Layout:**
  * **Tab 1 - Overview:** Visualisasi tren pendapatan harian/bulanan dan distribusi penjualan per wilayah.
  * **Tab 2 - Product Performance:** Analisis produk terlaris (*Top Selling*) vs produk di bawah target.
  * **Tab 3 - Raw Data & Insights:** Tabel data interaktif dengan pencarian, pengurutan, serta *download report* (CSV).

---

## 🛠️ Pustaka & Teknologi

* **Python:** 3.10+
* **Framework UI:** [Streamlit](https://streamlit.io/)
* **Visualisasi Data:** Plotly Express
* **Pengolahan Data:** Pandas & NumPy
